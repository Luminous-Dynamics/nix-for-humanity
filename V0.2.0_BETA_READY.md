## 🚀 Deployment Instructions

### For Users
```bash
# Download and extract
tar -xzf luminous-nix-v0.2.0-beta.tar.gz
cd luminous-nix

# Deploy
./deploy.sh

# Use it!
nix-ask "install firefox"  # Natural language NixOS
```
