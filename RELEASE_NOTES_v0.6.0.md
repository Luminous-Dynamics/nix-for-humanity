## 🔄 Migration Guide

### From v0.5.x to v0.6.0

1. **Update Dependencies**:
   ```bash
   git pull
   poetry install
   ```

2. **No Breaking Changes**: All v0.5.0 commands still work

3. **New Commands Available**:
   - `ask-nix dna` - Configuration DNA analysis
   - `ask-nix modes` - System mode management  
   - `ask-nix health` - Predictive health monitoring

## 🎯 Quick Start

### Try Configuration DNA
```bash
# Analyze your current configuration
ask-nix dna analyze

# See configuration evolution
ask-nix dna lineage

# Get improvement suggestions
ask-nix dna evolve
```

### Switch System Modes
```bash
# See available modes
ask-nix modes list

# Switch to gaming mode
ask-nix modes switch gaming

# Get AI recommendations
ask-nix modes recommend
```

### Check System Health
```bash
# Full health check
ask-nix health check

# Predict disk usage in 30 days
ask-nix health predict disk_usage --days 30

# Get optimization tips
ask-nix health optimize
```
