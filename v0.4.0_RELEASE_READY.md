### To Release
```bash
# 1. Update version
poetry version 0.4.0

# 2. Build standalone binary
./scripts/build-standalone.sh

# 3. Test the binary
./dist/luminous-nix --version
./dist/luminous-nix help

# 4. Create git tag
git add -A
git commit -m "Release v0.4.0: Configuration Generation & Flake Management"
git tag -a v0.4.0 -m "Release v0.4.0"
git push origin main --tags

# 5. Create GitHub release
gh release create v0.4.0 \
  ./dist/luminous-nix \
  ./dist-simple/luminous-nix-standalone.tar.gz \
  --title "v0.4.0: Natural Language Configuration & Flakes" \
  --notes-file RELEASE_NOTES_v0.4.0.md

# 6. Publish to PyPI
poetry publish --build
```
