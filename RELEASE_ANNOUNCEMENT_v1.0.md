## 🚀 What is Luminous Nix?

Luminous Nix lets you manage NixOS using plain English:

```bash
# Instead of memorizing commands...
nix-env -iA nixos.firefox

# Just say what you want!
luminous-nix "install firefox"
luminous-nix "find me a markdown editor"
luminous-nix "update my system"
```

## 📦 Installation

### Quick Install (No Dependencies!)

```bash
# Download standalone executable
curl -L https://github.com/Luminous-Dynamics/luminous-nix/releases/download/v1.0.0/luminous-nix-standalone.tar.gz | tar xz
./luminous-nix-standalone/install.sh

# Ready to use!
luminous-nix help
```

### For Developers

```bash
git clone https://github.com/Luminous-Dynamics/luminous-nix
cd luminous-nix
nix develop  # or nix-shell
poetry install
poetry run ask-nix help
```
