## 🎯 Major Breakthrough: HRM v1 Integration

### What is HRM?
The **Hierarchical Reasoning Model (HRM)** is a specialized 27M parameter AI model trained specifically for NixOS tasks. Unlike general-purpose LLMs, HRM understands NixOS patterns deeply and responds instantly.

## 📦 Installation

### Method 1: Standalone (Recommended)
```bash
# Download and extract
wget https://github.com/Luminous-Dynamics/luminous-nix/releases/download/v0.1.0-alpha/luminous-nix-v0.1.0-alpha-standalone.tar.gz
tar -xzf luminous-nix-v0.1.0-alpha-standalone.tar.gz
cd luminous-nix-v0.1.0-alpha-standalone

# Install dependencies
./install.sh

# Run!
./luminous-nix "install firefox"
```

### Method 2: Poetry (Developers)
```bash
git clone https://github.com/Luminous-Dynamics/luminous-nix
cd luminous-nix
poetry install
./bin/ask-nix "search text editor"
```

## 📊 Technical Specifications

### HRM Model Details
- **Parameters**: 27 million
- **Training Data**: 1000 NixOS examples
- **Accuracy**: 88-95% on NixOS tasks
- **Response Time**: <0.1ms
- **Model Size**: 100MB
- **Memory Usage**: 50MB

### System Requirements
- **OS**: NixOS or Linux with Nix
- **Python**: 3.9 or higher
- **Disk**: 200MB (including HRM model)
- **RAM**: 100MB minimum
- **Optional**: Ollama for general knowledge

## 🚧 Known Limitations

This is an **alpha release**. Here's what doesn't work yet:

1. **Voice Interface** - Architecture only, not functional
2. **Learning System** - Not activated
3. **Some Cache Methods** - Framework present, not all implemented
4. **GUI** - Planned for v0.4.0
5. **Advanced Config Gen** - Basic templates only

**Important**: If HRM model file is missing, falls back to simulation mode.
