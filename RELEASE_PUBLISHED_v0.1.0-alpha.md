## Installation Instructions

Users can now download and install:

```bash
# Download the release
curl -L https://github.com/Luminous-Dynamics/luminous-nix/releases/download/v0.1.0-alpha/luminous-nix-v0.1.0-alpha-minimal.tar.gz -o luminous-nix.tar.gz

# Extract
tar xzf luminous-nix.tar.gz

# Install
cd luminous-nix
./install.sh

# Test
luminous-nix help
luminous-nix "list installed"
```
