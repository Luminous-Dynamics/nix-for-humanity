class CausalReasoning:

    def analyze_failure(self, error: Error) -> CausalChain:
        """
        Traces error back to root cause

        Example:

        Error: "cannot find crate for `std`"

        Causal Chain:
        1. Immediate Cause: rustc can't find standard library
        2. Why? rustup toolchain is incomplete
        3. Why? User ran `rustup update` but it failed halfway
        4. Why? Network connection dropped during download
        5. Root Cause: Incomplete toolchain installation

        Solution: rustup toolchain install stable --force-reinstall

        Prevention: I'll verify toolchain integrity before builds
        """

    def counterfactual_analysis(self, decision: Decision) -> List[Alternative]:
        """
        "What if you had done X instead?"

                 • If you had run tests first (5 min):
                   - Bug caught before deployment
                   - Zero downtime
                   - 2 hours saved

                 • If you had staged deployment (15 min):
                   - Bug caught in staging
                   - Minimal impact
                   - Learning opportunity

                 This pattern has happened 3 times this month.
                 Shall we make testing mandatory? [Yes] [No] [Sometimes]"
